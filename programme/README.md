# Approved day-by-day programme only

24–31 January 2027. Extracted from the approved RU / EN / ZH standalone programme.
Only the eight day cards are embedded in the existing website. No hero, participation terms, prices, navigation, registration or footer is imported.

Each language inherits the original website language links. Same-origin iframe isolation prevents the programme CSS from changing any other section. resize.js reports the actual content height; the parent validates both message origin and frame identity. Images and fonts are shared, content-addressed files. Original cropping, watermarks and translated alt text are retained.

Sources and licence documents remain in SOURCES-AND-LICENCES.html; they are not linked in the guest interface. This record does not establish public reuse permission.
